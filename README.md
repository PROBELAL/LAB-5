# LAB-5: Calculator Testing and GitHub Actions

This project contains a JavaScript calculator, automated unit tests, and a GitHub Actions workflow.

## Project structure

- `src/calculator.js` contains the Calculator class.
- `test/calculator.test.js` contains the automated test cases.
- `.github/workflows/tests.yml` runs the tests on pushes to `master`.

## Run the tests

```bash
npm test
```
